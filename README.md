# Fundamentals of Data Science - Assessment Tool 3

## Exploratory Data Analysis Based Practical Assessment

This project contains Python code for all five EDA questions.

### Questions
1. Education Analytics Dataset
2. Healthcare Analytics Dataset
3. Retail Sales Dataset
4. Banking Loan Approval Dataset
5. Agriculture Crop Yield Dataset

## Requirements

Install Python 3.10+ and the required packages:

```bash
pip install pandas matplotlib
```

## Run the project

Open Command Prompt in this folder and run:

```bash
python eda_assessment.py
```

The program prints:
- Number of rows and columns
- Data types
- Missing values
- Duplicate values
- Mean
- Median
- Minimum
- Maximum
- Standard deviation
- Correlation with the selected target

It also creates:
- Histograms
- Box plots
- Bar charts
- Scatter plots
- Correlation matrices
- CSV statistical summaries

All generated files are saved automatically inside the `outputs` folder.
